GITHUB ACTIONS NOTES
================================================================

RSS feeds: collected via Python feedparser in the collect.yml workflow.
Steam API: GET https://store.steampowered.com/api/featuredcategories/
           + /appdetails?appids=XXX — no key required for public data.
SteamSpy:  GET https://steamspy.com/api.php?request=all — free, rate-limited.
X API:     Requires paid Basic tier. Store bearer token in GitHub Secrets
           as TWITTER_BEARER_TOKEN.
OpenAI:    Store key in GitHub Secrets as OPENAI_API_KEY.
